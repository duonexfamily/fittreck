# Релиз FitTrack

Чек-лист и готовые тексты для запуска prod-бота `@fittrack_check_bot`.

## 1. Тексты для BotFather

Всё задаётся в `@BotFather` → `/mybots` → `@fittrack_check_bot` → **Edit Bot**.

**Name** (`/setname`):

```
FitTrack — здоровье и тренировки
```

**About** (`/setabouttext`, до 120 символов — видно в профиле бота):

```
Тренировки, питание, сон и самочувствие в одном месте. Бесплатно, без рекламы. Не заменяет врача.
```

**Description** (`/setdescription`, до 512 символов — видно до нажатия «Старт»):

```
Привет! Я помогаю следить за здоровьем без лишних усилий.

🍽 Дневник питания и норма калорий
💧 Вода и вес
🏋️ Тренировки с подходами, шаблоны и календарь
😴 Сон и самочувствие — чек-ин в пару нажатий
📈 Графики, серии дней и достижения

Напомню о главном в удобное время. Бесплатно и без рекламы.

ℹ️ Приложение носит информационный характер и не заменяет консультацию врача.
```

**Commands** (`/setcommands`). Бот выставляет их сам при запуске, вручную — только если сбились:

```
start - Начать
checkin - Чек-ин: сон и самочувствие
settings - Напоминания
help - Что умеет бот
delete_me - Удалить все мои данные
```

**Botpic** (`/setuserpic`): квадрат 640×640, простой знак на однотонном фоне (например, пульс
или гантель), без мелкого текста — в списке чатов картинка совсем маленькая.

**Menu Button** бот ставит сам (`set_chat_menu_button`, кнопка «Открыть»). В `/mybots` → Bot Settings →
Menu Button ничего менять не нужно.

## 2. Проверка перед релизом

Проверить на двух телефонах — iOS и Android, в светлой и тёмной теме Telegram.

- [ ] `/start` новым аккаунтом: приветствие, дисклеймер, кнопка открывает анкету.
- [ ] Анкета → норма калорий на главном экране.
- [ ] Питание: добавить продукт поиском, быструю запись, воду. Удалить запись.
- [ ] Вес: записать, график появился.
- [ ] Тренировка: создать, добавить подходы, завершить. Шаблон, календарь.
- [ ] Чек-ин в Mini App и `/checkin` в боте — оценки сохраняются, серия растёт.
- [ ] «Прогресс»: все 4 периода открываются, касание графика показывает значение,
      подписи не налезают, «Всё время» на длинных данных — по неделям.
- [ ] Рекорды и достижения после завершённой силовой тренировки.
- [ ] `/settings`: включить «Итог дня» и «Итог недели», сдвинуть время, проверить, что пришли.
- [ ] Кнопка «Назад» Telegram на каждом экране, MainButton там, где есть сохранение.
- [ ] Открыть Mini App, подождать сутки, открыть то же окно — плашка «Сессия устарела».
- [ ] `/delete_me` тестовым аккаунтом: «Отмена» ничего не трогает, «Да» — данные пропали, `/start` начинает с анкеты.
- [ ] Цвета: нигде нет белых пятен в тёмной теме, ошибки читаются.

## 3. Инфраструктура

- [ ] Railway → Variables: `ENV=prod`, `BOT_TOKEN`, `WEBHOOK_SECRET`, `DATABASE_URL`. Лишнюю
      `KEEPALIVE_MINUTES` можно удалить — на Railway самопинг не нужен.
- [ ] Последний деплой зелёный, `/health` отвечает 200.
- [ ] Пробный период Railway заканчивается около 03.12.2026 — до этого решить, как продлевать.
- [ ] Бэкап БД: Railway → Postgres → Backups (или `pg_dump` вручную перед релизом).

## 4. Дисклеймер

Есть в приветствии `/start`, в описании бота, внизу главного экрана Mini App и в «Наблюдениях»
на экране «Прогресс». Если добавляются советы по питанию или тренировкам — дисклеймер рядом с ними.
